# Estratégia No-Code — Holocron Career AI

## Por que no-code para você agora

1. **Tempo:** SAA-C03 em 80 dias — codificar SaaS compete com estudo.
2. **Uso imediato:** Airtable + Make funcionam hoje, não em 2 semanas.
3. **Portfólio suficiente:** arquitetura + automação + IA documentada > repo vazio.
4. **Alinhamento:** você já vive no Obsidian; CRM visual complementa, não substitui o cérebro.

## O que "8 agentes" vira no no-code

| Agente | Ferramenta | Modo |
|---|---|---|
| Search | Make.com | Automático (RSS) |
| Matching | Claude Project | Semi-auto (colar vaga → score) |
| Resume | Claude Project | Manual (sob demanda) |
| Cover Letter | Claude Project | Manual |
| Application Assist | Airtable checklist | Manual |
| CRM | Airtable nativo | Automático (status) |
| Interview Prep | Claude Project | Manual |
| Learning | Airtable charts + revisão semanal | Semi-auto |

**IA nunca inventa fatos** — mesma regra; prompts fixos no Claude Project com seu CV anexado.

## Fluxo diário (15 min setup + 45 min)

```
1. Make importou vagas novas overnight → Airtable "Inbox"
2. Você abre Interface Airtable → triagem (5 min)
3. Vaga boa → colar descrição no Claude Project → Match Score (5 min)
4. Score ≥ 70 → pedir CV adaptado + cover letter (10 min)
5. Aplicar manualmente → mover card para "Aplicada"
6. Commit diário saa-c03-journey (5 min)
```

## Integração Obsidian ↔ Airtable

| Direção | Como |
|---|---|
| Obsidian → Airtable | Import único CSV das candidaturas atuais |
| Airtable → Obsidian | Export semanal CSV → nota de revisão |
| Estratégia | Permanece no Obsidian (fonte da verdade) |
| Diário público | saa-c03-journey (GitHub) |

Não sincronizar bidirecional em tempo real — evita complexidade.

## Limites honestos do no-code

- ❌ Scraping LinkedIn automatizado (mesmo no-code — ToS)
- ❌ Multi-tenant SaaS comercial (precisaria Bubble + backend)
- ❌ RAG programático fino (Claude Project cobre 80%)
- ✅ CRM, KPIs, RSS, alertas, IA assistida — **100% coberto**

## Quando reconsiderar código

Só se:
- > 5 usuários pagantes pedindo SaaS, ou
- Make.com free insuficiente (> 1000 ops/mês), ou
- quiser Holocron Career como produto depois da certificação.

Até lá: **no-code é a decisão correta.**
